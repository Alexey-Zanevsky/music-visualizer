MUSIC VISUALIZER
for Spotify

Connect your Spotify account to start the visualizer.

01
Create a Spotify App

Open the Spotify Developer Dashboard and click Create app.

02
Enter app details

Set the name and description to Music Visualizer App and leave Website empty.

03
Add the Redirect URI

Add http://127.0.0.1:5500 to Redirect URIs.

04
Select Web API

Check Web API and agree to Spotify's Developer Terms of Service and Design Guidelines . Cick Save to create the app.

05
Add your Client ID

Copy the Client ID from your Spotify app and replace YOUR_CLIENT_ID in spotify.js.

06
Connect Spotify

Start a song in Spotify, click the button below, then sign in and authorize the application.

Your Spotify account is used only to read playback information.
